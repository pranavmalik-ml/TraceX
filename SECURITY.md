# Security Policy

TraceX is an early-stage research prototype and is not designed or certified for production financial systems.

## Reporting a vulnerability

Please do not publish sensitive transaction data, credentials, or exploitable details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile.

## Data handling

Never submit real banking records, personal data, API keys, passwords, or other secrets to this repository. Use synthetic or properly anonymised data only.
